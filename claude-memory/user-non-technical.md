The user has stated they are "not super tech savvy" and needs things explained.

Avoid unexplained jargon (env vars, API, PATH, interpreter). When a technical
step is unavoidable, say what it is in plain words and why it matters before
naming it. Prefer giving click-by-click GUI instructions over command-line
steps when both are possible. Don't assume they know what a terminal, a
Python install, or a scripting API is.
